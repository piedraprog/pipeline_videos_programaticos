# Claude instructions

The working rules for this repository are in `AGENTS.md`, shared by every coding agent. Read it before making a video or changing the pipeline; start with its "Working format" section.

@AGENTS.md

## Reminders that are easy to miss

- This repository is public. Client and unreleased material lives only under `private/`; the privacy check runs on commit, on push and in CI.
- Use the canvas renderer for `demo` plans and iterate by parts: a narration or music change must not render the picture again.
- Report what you verified and what you did not. Frames inspected is not the same as the video watched or the audio heard.
- Never start a development server for another project, or write to a shared database, without the owner asking for it.
